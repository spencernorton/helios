# Helios GIF demos

Short loops recorded in Helios 0.114.4 with a fictional project and staged
conversations. These show real app interactions; the browser loop trims one
idle interval. Each GIF loops at 12 fps and has a still fallback and silent
MP4 equivalent. File names include content hashes so cached media stays current.

- [Draft a prompt and add a project-file reference.](composer-5064c50cc15b.gif)
- [Inspect the actual diff, then stage and unstage a Git hunk.](git-review-3a2348523f66.gif)
- [Preview a local app and attach its screenshot to the chat.](browser-preview-09c48384e3ae.gif)
