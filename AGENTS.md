# Helios contributor guidance

Helios is a native GTK4/libadwaita Linux coding desktop. Follow CONTRIBUTING.md
for development dependencies and the required backend, native GTK and installed
package acceptance checks. Keep changes on a branch and preserve existing work.

Document shipped behaviour from the current source. Provider models, reasoning,
permissions, native commands, quotas and image support differ; a roadmap or a
disabled command is not evidence that a feature is available. Keep setup
instructions aligned with the actual Settings labels and state-directory rules.

Keep demonstrations fictional and isolated from real histories and accounts.
Never commit credentials, private prompts, personal paths or local infrastructure
details. Public documentation and media should explain any staged provider
content. Record meaningful changes as a new top entry in AGENTS/journal.md;
preserve earlier entries.
